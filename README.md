# Pulse

Windows용 오토마우스 · 자동 키보드 · 매크로 앱 **Pulse**의 사이트입니다. — [Exstruo](https://github.com/ExstruoHQ)

사이트: https://exstruohq.github.io/pulse/

## 내용

| 경로 | 설명 |
| --- | --- |
| `index.html` | 사이트 한 장 (한국어 / English, 브라우저에서 바로 써 보는 자동 클릭 화면 포함) |
| `downloads/PulseSetup-1.0.0.exe` | 설치 프로그램 (관리자 권한 불필요, 설정 → 앱에서 제거) |
| `downloads/Pulse-1.0.0-portable.zip` | 설치 없이 쓰는 PULSE.exe |
| `fonts/` | Archivo (OFL), G마켓 산스 — 각 라이선스 파일 포함 |

## 새 버전 올리기

1. `downloads/` 의 두 파일을 새 버전으로 바꿉니다.
2. 파일 이름이 바뀌면 `index.html` 맨 아래 `DOWNLOADS` 의 주소와 본문의 버전 · 크기 표기를 고칩니다.
3. 커밋하고 푸시하면 GitHub Pages에 1~2분 안에 반영됩니다.

## 미리 보기

정적 파일이라 아무 웹 서버로나 열 수 있습니다. 예: `python -m http.server` 또는 VS Code Live Server.
